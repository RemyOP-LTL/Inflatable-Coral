# polyps/fabric-pattern/

## Purpose
Flat nylon fabric pattern for a polyp, sewn together, with string channels. Same fabric type as inflatable costumes.

## Design intent (from Remy)
- The string runs through a channel on the inside of each finger (toward the centre), and the strings tie together at the centre. The alternative is a single pull from the centre. Not yet chosen.
- The polyp must inflate with air and collapse when the string is wound.

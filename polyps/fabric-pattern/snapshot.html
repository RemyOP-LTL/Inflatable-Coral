String pull

Five cords run from the fingertips along the inner seams to one hitch point 1 in below the centre point. The hitch is pulled down in 1 in steps. Constant air pressure, no tunnel friction.

Run the tool on your Mac

The tool lets you change cuff diameter, cuff length, finger length and more, and runs the simulations. It needs no typing in a terminal.

  1. Download the project as a zip (GitHub asks you to sign in) and open the zip from Downloads.
  2. Open the folders polyps, then fabric-pattern.
  3. Right-click Run Polyp Tool.command, choose Open, then Open again. You only need the right-click the first time.
  4. Wait while it sets itself up (a few minutes, once). Your browser opens with the tool.

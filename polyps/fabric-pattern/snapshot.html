Run the simulator on your Mac

Set it up once. After that the simulator is always one link away, and it pulls my latest changes with one button.

  1. Open the Terminal app and paste this line, then press Return. It takes a few minutes the first time, and it is safe to paste again later. 
    ([ -d ~/coral-simulator ] || git clone https://github.com/RemyOP-LTL/Inflatable-Coral.git ~/coral-simulator) && cd ~/coral-simulator && git fetch origin && git checkout claude/polyp-string-fingers && git pull && bash polyps/fabric-pattern/install-mac.sh
    If macOS asks to install developer tools, accept, wait, and paste the line again.
  2. Open the simulator and bookmark it. It only loads after step 1. (This is a different address from your skin simulator.)
  3. When I say I've pushed changes, open the simulator, pick the branch I name in the Version box, and press Get latest changes.
